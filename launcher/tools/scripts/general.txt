# JSRF-PC Tools: its general functionality, played by the script mode.
#
#   jsrf-pc-tools [JSRF-PC's folder] --script general.txt --out <folder>
#
# Run it only on a copy of a JSRF-PC folder (its data/saves): it saves,
# loads, clears, imports and deletes there. Beside this file: pictures/ (the
# Graffiti page's pictures) and import-source/ (a folder of saves to import
# from, such as a copy of a data/saves). Each step goes to script.log in
# the out folder, with the screenshots; the exit code is how many failed.

note ---- The window and its pages
expect-text JSRF-PC Tools
expect-text Scale
expect-text JSRF-PC's saves
expect-text Save slots
expect-text Backups
expect-text Other emulators
shot 01-save-manager
tab Graffiti
expect-text Pictures
expect-text Designs
expect-text Import
shot 02-graffiti
tab Missions
expect-text Start states
expect-enabled Make start states
shot 03-missions
tab Build
expect-text Engine
shot 04-build

note ---- Graffiti: pictures in, and imported as designs
tab Graffiti
answer $HERE/pictures
click Pictures > Add folder...
wait
expect-text star-badge.png
expect-text 1 file couldn't be read
click ~couldn't be read
expect-text not-a-picture.png
shot 05-graffiti-pictures
click Designs > ~##tile@1
wait
click Cropped
click Stretched
click Whole, clear margins
shot 06-graffiti-design
click Import > Import
expect-text Import
click Import
wait 120
expect-text Imported
shot 07-graffiti-imported
click Clear imported
wait

note ---- Save slots: save, rename, hover, load, clear
tab Save manager
wait

type Script test
key enter
wait

key ctrl+a
type Script test renamed
key enter
wait
expect-text Script test renamed

expect-text Saved from JSRF-PC's saves
shot 08-slot-hover

click Load
wait
expect-text Loaded slot 8.

expect-text Before loading slot 8
shot 09-slot-loaded
click Save slots > Clear
click Clear
wait
expect-text Slot 8 cleared.
expect-no-file $SAVES/Save slots/8/about.txt
