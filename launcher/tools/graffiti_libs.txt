# The picture libraries JSRF-PC Tools' graffiti page is built with (b3 row
# 35), read by tests/graffiti/run.py, as the tool's build will read it, so
# the tool and its test build the same files. Each is the library's own
# code, built with its own warnings (-w) and the flags its group gives:
#
#   @group <name> <flags>   the files after it, until the next group
#   <file>                  a source, from the repository's top
#   <file> linux|windows    only on that system
#
# Paths in flags are from the repository's top too. Each library's version,
# what's taken of it and its licence are in its README.md in third_party/,
# and in NOTICE.
