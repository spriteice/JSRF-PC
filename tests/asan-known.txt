# The address and undefined-behaviour sanitizers' known reports, for
# tests/run_all.py --asan. Each line is one known bug, still open, in the
# maintainer's known-bugs.md:
#
#   test | the report's SUMMARY line | fixed by | the bug, and what removes it
#
# In the line, * stands for any text, and paths are from the repository's
# root, as in
#
#   SUMMARY: AddressSanitizer: heap-use-after-free src/platform/win32_compat.c:* in *
#
# A leak's line is run_all's own, of the same shape, naming the first place
# in the repository it was allocated from, as in
#
#   SUMMARY: LeakSanitizer: leak from src/platform/win32_compat.c:* in cv_lazy_init
#
# "Fixed by" is the release that is to fix the bug (b3, 1.0), checked at that
# release's step 4 (docs/release-checklist.md). The report is shown on the
# run but doesn't fail it; any other report does.
# A bug's lines come out with the change that fixes it, and the sanitizers
# must then find nothing there.
